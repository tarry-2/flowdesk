# FLOW 워크스페이스

코인·물류·창업 업종을 전환하는 반응형 프런트엔드 프로토타입입니다.

- `dist/config.js`: 업종 이름, 메뉴, 단위, 강조색, 지표, 상품, 예시 데이터.
- `dist/app.js`: 공통 화면과 업종별 신청·브리지 동작. 실제 서비스 연동은 이 동작 계층을 API 어댑터로 분리해서 연결합니다.
- `dist/style.css`: PC 사이드바, 카드 그리드, 모바일 하단 메뉴 및 반응형 스타일.
- `dist/index.html`: 공통 문서와 앱 셸.

실행: `python3 -m http.server 4173 --directory dist`

업종을 추가하려면 `SECTORS`에 동일한 형태의 설정을 추가하고 선택 항목 및 필요한 업무 동작을 연결합니다. 기존 세 업종의 표시 문구·상품·단위·색상은 설정 파일에서 변경할 수 있습니다. 업무 규칙과 실제 API는 업종에 맞는 별도 구현이 필요합니다.

현재 실제 로그인·지갑·송금·스테이킹·배송 접수·상담 접수·보상 지급은 연동되지 않았습니다. 모든 값은 예시이며 신청은 현재 페이지 세션에서만 유지됩니다. 업종 선택만 기기의 localStorage에 저장합니다. Google Fonts가 불가능하면 시스템 글꼴을 사용합니다.

## 디자인·추천 시안 추가
- `/#admin`: 디자인 관리자, 실시간 PC/모바일 미리보기, 기기 로컬 저장.
- `/#member`: 데모 계정과 인증 상태. `/#join`: 데모 가입.
- `/?ref=추천코드#join`: 친구 초대 화면. 외부 기기 추천 연결은 서버 연동 필요.
- `dist/design.js`: 디자인 설정 검증, 프리셋, 편집·미리보기·저장.
- `dist/referral.js`: 브라우저 로컬 회원·추천 프로토타입.
- `PRODUCT-REQUIREMENTS.md`: 실제 회원·추천·보상 운영에 필요한 구현 범위.
